# Lucky 的日常

Lucky 的猫咪贴纸相册与日记。收录 11 段视频和 13 张独立照片，合计 24 条记录，支持立体封面、纸页翻阅、六个主题章节与全部浏览、静音悬停预览和大图查看。

根据 Lucky 的真实照片创作了猫耳拟人虚拟形象和两张表情贴纸；封面可看到真实 Lucky 与虚拟 Lucky 的对照。

这是一个可直接部署到 GitHub Pages 的静态网站，不需要安装依赖或构建。

## 内容

最新一轮新增七张独立照片，记录 Lucky 在夜晚窗边、键盘旁伸爪、桌边张望、沙发休息和蜷卧的画面。此前补收录 21256、21258、21267 三段视频和两张独立照片。21256 记录客厅／窗边环境，画面中没有清晰看到 Lucky；21258 和 21267 记录窗边笼子里的 Lucky。

另补录此前遗漏的 21126、21128、21165 三段独立视频，分别记录航空箱内抬头、箱内转身，以及沙发布罩边走动，对应 `lucky-09.mp4`、`lucky-10.mp4`、`lucky-11.mp4`。

重复提供的 21204 视频和原有四张照片沿用已有记录，不再次收录。最新七张照片来自另一上传批次，与上一轮同名的照片不是重复画面。六个主题章节为“相伴时光”“窗边小家”“家里的新日常”“初见 Lucky”“和小鸟”“吃饭与小睡”，另有“全部片段”浏览。

源文件与网页素材的对应关系见 [MATERIALS.md](MATERIALS.md)。按用户选择，原始 MOV 不纳入仓库。

## 更新相册

- 编辑 `content.js` 修改记录、标题、日期、照片与视频路径。
- 照片和视频放在 `assets/`。视频为 H.264/AAC MP4，封面直接取自视频。
- `app.js` 负责日记与媒体查看，`album.js` 负责相册与动效。
- `styles.css` 和 `album.css` 负责样式与手机适配。

日期表示收录日期。所有照片和视频由猫咪主人提供。

## 本地浏览

在此目录运行 `python -m http.server 4173`，然后打开 `http://localhost:4173/`。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 `main` 和 `/(root)`。`.nojekyll` 保证按静态文件直接发布。

所有资源使用相对路径，支持仓库子路径部署。默认相册在 `#/`，虚拟形象在 `#/character`，日记列表在 `#/notes`，单篇记录在 `#/note/...`。

## 效果

支持跳过封面、键盘与触摸翻页，遵循系统的“减少动态效果”设置。视频详情由用户手动播放，保留原声；桌面鼠标悬停的预览为静音，省流量模式下不启用。

页面效果参考 https://squadbook.com/cats/ ，使用独立实现与 Lucky 的原素材。
