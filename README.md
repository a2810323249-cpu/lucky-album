# Lucky 的日常

Lucky 的静态猫咪日记与贴纸相册，包含立体封面展开、纸页翻阅、章节切换、卡片微倾斜与光泽、静音悬停视频预览，以及深色媒体查看器。

另有依据 Lucky 照片制作的本猫像素形象、动作贴纸和绘本风拟人设定。形象页位于 `#/character`，相册封面也展示真实 Lucky 与像素形象的对照。本猫形象沿用主人选定的柔和坐姿造型：三个月大的长尾母三花、奶白长毛、烟灰与浅杏斑块、粉色鼻子和蓬松灰尖尾巴。旧版图像保留在仓库中，形象页可并排查看新旧版本。

桌面左下角、手机右下角有可互动的 Lucky 像素网页桌宠，保持四足小猫造型。可以轻点摸摸、玩耍、睡觉与叫醒，拖动或用方向键移动，收起后可唤回；声音默认关闭，位置和偏好仅保存在当前浏览器。网页桌宠独立于 ChatGPT/Codex 的桌宠，不读取其任务状态。

## 内容

共收录 11 段视频和 13 张独立照片，合计 24 条记录。最新一轮新增七张照片，包括夜晚窗边、键盘旁伸爪、桌边张望、沙发休息及蜷卧画面。原有视频由用户提供：21134.mov、21148.mov、21164.mov、21191.mov、21204.mov；此前补收录 21256、21258、21267、21126、21128、21165 六段独立视频，以及两张独立照片。网页使用保留原方向和声音的 H.264/AAC MP4，封面直接从各视频提取；独立照片按用户提供的原文件收录。

21256 记录客厅／窗边环境，画面中没有清晰看到 Lucky；21258 和 21267 记录窗边笼子里的 Lucky。

补录的 21126、21128、21165 分别记录航空箱内抬头、箱内转身，以及沙发布罩边走动，映射为 `lucky-09.mp4`、`lucky-10.mp4`、`lucky-11.mp4`。

此前重复提供的 21204 视频和原有四张照片沿用已有记录，不再次收录。最新七张照片属于新的上传批次；与上一轮同名的照片不是重复画面。重新核对后，网站现有 24 条记录的媒体各不相同；相似的仰躺照、航空箱视频也分别记录了不同动作，因而保留。

源文件与网页素材的对应关系见 [MATERIALS.md](MATERIALS.md)。按用户选择，原始 MOV 不纳入网站或 GitHub 仓库。

文案仅描述视频中可见的内容。日期表示相册收录日期，不主张实际拍摄时间。示例照片与示例日记已移除。

## 像素形象制作

造型优先保留 Lucky 的幼猫轮廓、灰杏三花斑块和完整长尾，以成组的明暗像素画出脸颊、胸毛和尾巴的毛束，不靠模糊整图模拟绒毛。网页桌宠将尾巴、胸毛、耳朵、双爪与眼睛拆成可独立运动的图层：缓慢呼吸、偶发眨眼与耳颤、轻微爪部和尾巴动作；睡姿只作一次平滑切换。系统设置“减少动态效果”时停止循环动作。声音默认关闭，当前使用网页合成的轻提示音，并非从视频提取的猫叫声。参考了 [Saint11 的像素色块与轮廓教程](https://saint11.art/pixel_art_articles/article2/)、[Lospec 的选择性轮廓教程](https://lospec.com/articles/pixel-art-outlines-part-2-using-color/)；互动方式参考 [Aseprite 的动作分帧方法](https://www.aseprite.org/docs/animation)及 [oneko.js 的桌宠状态切换](https://github.com/adryd325/oneko.js)。网站使用独立制作的 Lucky 图像与代码。

## 拟人设定

角色页在本猫照片与像素形象之外，新增独立的 Lucky 猫耳女孩立绘与可点开查看原尺寸的设定稿。画风是柔和铅笔线与水彩色块，依据用户选择的第二版坐姿小猫构思：头发以奶白色为主，局部带烟灰、浅杏挑染，保留粉色鼻尖、圆眼睛和完整的灰尖蓬松长尾。暖白外套呼应 Lucky 的长毛。设定稿展示正反面、三种表情与耳尾细节；页面同时展示真实照片中的眼鼻与三花毛色，便于对照。拟人画是想象中的角色，不作为 Lucky 的真实照片或相册记录。原图文件为 `assets/lucky-human-portrait.png` 和 `assets/lucky-human-sheet.png`。

## 修改

- `content.js`：网站名字、介绍、日记、日期、媒体路径和说明。
- `assets/`：Lucky 的视频、封面、原照片和图标。
- `styles.css`：响应式样式。
- `album.css`：书册、贴纸、纸页和动效样式。
- `album.js`：六个主题章节与全部浏览、分页、立体开合、触摸翻页、悬停预览与动效清理。
- `app.js`：日记、相册、虚拟形象、视频放大查看、键盘切换与关闭。
- `pet.js`、`pet.css`：网页桌宠的互动和分层动作。

在项目根目录运行 `python -m http.server 4173` 即可本地浏览。静态托管使用 hash 路由，无需额外路由配置。

详情视频由用户手动播放，使用原生播放控件和移动端内嵌播放，关闭或切换时会暂停视频。

相册默认位于 `#/`，兼容原有 `#/photos`；日记列表位于 `#/notes`，原有 `#/note/...` 链接保持有效。六个主题章节分别为“相伴时光”“窗边小家”“家里的新日常”“初见 Lucky”“和小鸟”“吃饭与小睡”，另有“全部片段”浏览。

首次打开有可跳过的封面动画；系统设置“减少动态效果”时直接打开并关闭倾斜、光泽、翻页和预览效果。桌面鼠标悬停的视频预览为静音，移开鼠标即暂停并释放媒体；省流量模式下不启用预览。大图、详情视频保留原生控件与原声。手动播放的详情视频不会自动播放。

效果参考：https://squadbook.com/cats/ 。参考公开页面源码中可确认的立体封面、贴纸布局、章节渐变、卡片倾斜及媒体查看效果，使用独立实现与 Lucky 的原素材，没有复制参考站的图片、账号、抽包或付费功能。新增纸页翻阅为个人相册的适配效果。
